📖 100% Free Online Setup Guide (Shahid & Adnan Ke Mobile Par Chalanay Ka Tareeqa)

Guide Kholiye / Band Karein ▼
1. Free Firebase Database (2 Minute)
  1. Apne mobile/PC me console.firebase.google.com kholein (Gmail login).
  2. "Add project" dabayein aur project name nethisab likhein.
  3. Left menu me "Build ➔ Realtime Database" dabayein.
  4. "Create Database" dabayein ➔ Location select karein ➔ "Start in test mode" select karein (is se read/write allow ho jata hai).
  5. Upar jo URL likha aye (jaise https://nethisab-xxxx.firebaseio.com) wo copy kar ke upar Database URL me paste kar ke "Cloud Connect" daba dein!
2. Free Link Adnan Ko WhatsApp Bhejna
  1. Is pure folder ko Netlify Drop (drop.netlify.com) par drag-and-drop karein ya GitHub Pages par daalein (100% free life-time).
  2. Netlify aapko ek link dega jaise https://nethisab.netlify.app.
  3. Yeh link Adnan ko WhatsApp par send kar dein.
  4. Adnan jaise hi mobile par kholega, app chal paregi!
3. Mobile App Ki Tarah Save Karna (PWA)
  1. Adnan apne Android phone ke Google Chrome me link khole.
  2. Upar 3 dots ⋮ dabaye aur "Add to Home screen" ya "Install App" dabaye.
  3. iPhone par Safari me Share button ➔ "Add to Home Screen" dabaye.
  4. Mobile ki screen par NetHisab Pro ka asli App icon ban jayega!
  5. Ab na laptop on rakhna padega, na koi fees lagegi!
